\section{What Is An Extreme Event?}

\subsection{Defining emipirical return levels}
\begin{frame}
    \begin{itemize}
        \item Engineers and policy makers tend to use something called the $X$-year event. For example, the new drainage system can stand a 50-year rainfall.
        \begin{definition}[Return Level]
            The terminology $X$-year return level means a value that is expected \textbf{to be exceeded} exactly once in the next $X$ years.
        \end{definition}

        \item Another example: The 100-year event has a 1\% change of happening each year, meaning you expect to see at least one 100-year event every 100 years.
        \item Empirically, we can derive this from observation.
    \end{itemize}
\end{frame}

\begin{frame}
    \begin{columns}[T,onlytextwidth]
    \column{0.5\textwidth}
        \begin{definition}[Empirical Return Level]
            Let $Z$ denotes the distribution of Rx5day. Given ranked yearly maximum data $z_{(1)} \leq z_{(2)} \leq ... \leq z_{(m)}$, the probability of exceeding a value with rank $i$ data is
            \[
            P(Z > z_{(i)}) = 1 - P(Z \leq z_{(i)}) = 1 - i/(m+1)
            \]
            which corresponds to the the return year of $1/P(Z > z_{(i)})$.
        \end{definition}
    \column{0.5\textwidth}
        \centering
        \includegraphics[width=0.95\textwidth]{../figs/empirical_return_level.png}
        \vspace{0.2cm}
        {\scriptsize Empirical return level applied to Rx5day}
    \end{columns}
\end{frame}

\subsection{Uncertainty in empirical return level}
\begin{frame}
    \begin{columns}[T,onlytextwidth]
    \column{0.5\textwidth}
        \begin{itemize}
            \item A small change in the data series can have large consequences for the computation of return levels and return periods.
            \item For example, let's say we replace the recent extreme event in 2025 (the highest record) with a "common" annual maxima.
            \item Note that it's becoming uncertain to estimate the 100-year event by comparing both plots.
        \end{itemize}

    \column{0.5\textwidth}
        \centering
        \includegraphics[width=0.95\textwidth]{../figs/empirical_return_level_alt.png}
        \vspace{0.2cm}
        {\scriptsize Empirical return level applied to altered Rx5day}
    \end{columns}    
\end{frame}

\begin{frame}
    \begin{columns}[T,onlytextwidth]
    \column{0.5\textwidth}
        \begin{itemize}
            \item We can use bootstrapping method--\textit{"pulling oneself up by one's bootstraps"}.
            \item This method works by assuming that while we have limited data, the data that we do have is a representative sample of possible events.
            \item We use the data as a distribution to resample from and compute uncertainties using those.
            \item By resampling data from our observation, we also call this \textbf{non-parametric bootstrap} method.
        \end{itemize}

\end{frame}

\section{Classical Extreme Value Theory}

\subsection{Generalized extreme value (GEV) distribution}
\begin{frame}
    \begin{itemize}
        \item Empirical return values are not enough. We often need extrapolation and address the uncertainty from empirical return levels, which leads to extreme value theory (EVT)! \pause
        \item The classical EVT approach is to study the statistics of 
        \[M_n = \max (X_1, \ldots, X_n)\]
        where $X_i, \ldots, X_n$ is a sequence of independent random variables with a common distrubtion function $F$.
        \item Example: Let $X_i$ be 5-day precipitation. If $n$ is the number of observations in a year, $M_n$ corresponds to Rx5day. 
    \end{itemize}
\end{frame}

\begin{frame}
    \begin{theorem}[Limiting theory for block maxima]
        If there exists two sequences of real numbers $\{a_n > 0\}$ and $\{b_n\}$ such that 
        \[
        P((M_n - b_n)/a_n \leq z) = G(z) \text{ as } n \rightarrow \infty,
        \]
        then the CDF $G(z)$ is a member of the GEV distribution
        \[
        G(z) = \exp{ \left\{ -\left[ 1 + \xi \left( \frac{z-\mu}{\sigma} \right) \right]^{-1/\xi} \right\} }
        \]
        given $\{z : 1 + \xi(z-\mu)/\sigma > 0 \}$ and $\sigma>0$.
    \end{theorem} \pause

    \begin{alertblock}{Implication}
        \begin{itemize}
            \item For large $n$, $M_n$ can also be approximated by a different member of GEV distribution. 
            \item We can model appropriate annual maxima time series with GEV distribution: $\text{GEV}(\mu, \sigma, \xi)$!
        \end{itemize}
    \end{alertblock}
\end{frame}

\begin{frame}
    \begin{columns}[onlytextwidth]
    \column{0.5\textwidth}
    \begin{block}{Interpreting distribution parameters}
    \begin{itemize}
        \item $\mu$ : location
        \item $\sigma$ : scale
        \item $\xi$ : shape
    \end{itemize}
    \end{block}
    
    \column{0.5\textwidth}
    \centering
    \includegraphics[width=0.9\textwidth]{../figs/varying_params.png}
    \end{columns}
\end{frame}

\subsection{Maximum likelihood estimation (MLE)}
\begin{frame}
    \begin{itemize}
        \item The principle of MLE is to choose the model with greatest likelihood. Assume that $Z_1, ..., Z_m$ are independent variables having the GEV distribution. The likelihood function is
        \[ \ell(\mu, \sigma, \xi) = \prod_{i=1}^m P(\mu, \sigma, \xi \vert z_1, ..., z_m) \]
        given independent realizations of $z_1, ..., z_m$.
    \end{itemize}
\end{frame}

\begin{frame}
    \begin{itemize}
     \item The log-likelihood for the GEV parameters is
        \[
        \ell(\mu,\sigma,\xi)=
        \begin{cases}
        \displaystyle
        -\sum_{i=1}^m\log\sigma
        -\left(1+\frac{1}{\xi}\right)
        \sum_{i=1}^m
        \log\!\left[1+\xi\left(\frac{z_i-\mu}{\sigma}\right)\right]
        % \\[1.2em]
        % \displaystyle\qquad
        -\sum_{i=1}^m
        \left[1+\xi\left(\frac{z_i-\mu}{\sigma}\right)\right]^{-1/\xi},
        & \xi\neq 0,
        \\[2em]
        \displaystyle
        -\sum_{i=1}^m\log\sigma
        -\sum_{i=1}^m
        \left(\frac{z_i-\mu}{\sigma}\right)
        -\sum_{i=1}^m
        \exp\!\left\{
        -\left(\frac{z_i-\mu}{\sigma}\right)
        \right\},
        & \xi=0,
        \end{cases}
        \]
        subject to $1+\xi \left[ (z_i-\mu)/\sigma \right]>0, i=1,\dots,m.$
    \end{itemize}
    \begin{alertblock}{Implementation}
        \begin{itemize}
            \item We define estimated distribution parameters, $\hat{\mu}, \hat{\sigma}, \hat{\xi}$, as the solution to maximize $\ell(\mu, \sigma, \xi)$ given their respective domain.
            \item Here, I used \texttt{scipy.minimize} method to solve this numerically.
        \end{itemize}
    \end{alertblock}
\end{frame}

\section{Non-Stationary Analysis}
\subsection{Defining a new model}

\begin{frame}
    \begin{itemize}
        \item So far, the theory remains valid under the assumption of stationarity: the distribution parameters don't change over time.
        \item However, under the warming climate, we know this is an unlikely assumption.
        \item For instance, we know extreme precipitation scale \textbf{exponentially} with temperature, following the Claysius-Clapeyron relation.
    \end{itemize}
\end{frame}

\begin{frame}
    \begin{block}{Modeling temperature effect on Rx5day}
        Let $T(t)$ be GMST at year $t$. We define the Rx5day in year $t$ as
        $$
        Z_t \sim GEV(\mu(t), \sigma(t), \xi)
        $$
        with
        $$
        \mu(t) = \mu_0 \exp{\left( \alpha T(t) \right)}
        $$
        and
        $$
        \sigma(t) = \sigma_0 \exp{\left( \alpha T(t) \right)}
        $$
        where $\mu_0, \sigma_0$, and $\xi$ are the location, scale, and shape parameters of the distribution; and $\alpha$ is the trend due to GMST. 
    \end{block}
    \pause
    \begin{itemize}
        \item Here, we refer GMST as a \textbf{covariate}.
        \item We will again apply maximum likelihood estimation to fit $\mu_0, \sigma_0, \xi, \alpha$. This is done by updating $\mu=\mu(t)$, $\sigma(t)$, and $z_i$ to $z_t$ to the previous likelihood functions.
    \end{itemize}
    \pause
    \begin{alertblock}{Trend Detection}
        When the confidence interval for $\alpha$ does not include zero, we conclude that the GMST has a significant effect on Rx5day.
    \end{alertblock}
\end{frame}

\subsection{Results}

\begin{frame}
    \begin{itemize}
        \item The bootstrap method with 1,000 resamples is applied. Resampling is performed on paired Rx5day and GMST values.
        \item The bootstrap mean is used as the best estimate of the model parameters.
        \item Confidence intervals for the fitted parameters are constructed from the bootstrap resamples using the 2.5\% and 97.5\% quantiles.
        \item The confidence interval for $\alpha$ is $[0.25, 0.50]$.
    \end{itemize}

            \begin{definition}[Probability Ratio]
                Let $p$ be the probability of exceeding the 2025 Rx5day event under a given climate state (actual or counterfactual conditions). Define
                \[PR = p_{\text{actual}} / p_{\text{counterfactual}}.\] 
                If the confidence interval on the PR excludes one (no change), the distribution is significantly different between the two climates.
            \end{definition}

            \uncover<2-| hold>
            {
            \begin{itemize}
                \item The probability ratio is estimated to be 179.3 (95\% CI: 80.6--240.3).
                \item We can say \textit{the 2025 event is 179 more likely to happen under the current climate than under pre-industrial climate}.
            \end{itemize}
            }

\section{Final Remarks}
\subsection{Remarks}
\begin{frame}
    \begin{itemize}
        \item The non-parametric bootstrap should be interpreted with caution as it underestimates the real uncertainties involved in the frequency models \citep{kysely2008}.
        \item We can expand the non-stationary model to include climate variability, e.g ENSO and IOD.
        \item Trend detection is not attribution (to anthropogenic climate change)! 
        \begin{itemize}
            \item Detected trends may arise for a different reason than a change in global climate forcing.
            \item Attribution requires physical climate models that resolve the system dependent on prescribed external forcing.
        \end{itemize}
    \end{itemize}
\end{frame}
